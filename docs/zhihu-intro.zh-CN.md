# 在手机上继续家里电脑里的 Claude Code / Codex

![NekoNest 猫娘乐园](./images/nekonest-family.jpg)

有时电脑上的编码智能体还在跑，你已经离开桌面；或者只想在手机上补一句要求、
看进度、传一张截图，却不想重新建立一套远程桌面。

NekoNest（猫娘乐园）解决的是这段连接：

```text
手机 PWA ↔ 自己的 VPS ↔ 主机 Daemon ↔ 本地编码智能体
```

Daemon 由家里电脑主动向外连接，所以家庭网络不用开放入站端口。会话仍来自
Claude Code、Codex、Kimi CLI 和 Grok Build 的原生存储；NekoNest 负责在手机上
呈现、继续和控制当前明确支持的部分。

## 能做什么

- 按**目录 → 智能体 → 线程**查看最近的原生会话。
- 从手机发送提示词、查看流式输出和传送常用附件。
- 主机离线、重连或某项能力不可用时给出明确状态。
- Codex 的 app-server 路径可提供较完整的手机控制；其他智能体以兼容继续为主。

具体按钮由运行中的 Daemon 与已安装 CLI 探测决定，不靠宣传表格猜测。

## 适合谁

- 已经在 Windows 或 Linux 主机上使用编码智能体。
- 愿意维护一台带 HTTPS 的 VPS。
- 希望原生会话和模型凭据继续留在自己的电脑上。
- 需要“离开电脑后继续处理”，而不是把整个开发环境搬到云端。

## 安全边界

主机只出站连接，但手机权限仍然等同于对本地智能体的远程入口。公网部署必须使用
HTTPS、不同的管理员密钥和注册令牌，并保护 Server 数据与 Daemon 身份文件。
新实例默认使用 sealed 传输；选择 open 模式则表示接受 VPS 可读取应用正文。
